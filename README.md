# NetflixGPT
A smart web application that allows users to explore, discover, and search for movies. NetflixGPT provides an intuitive interface to browse content, view details, and find something great to watch. Whether you're exploring new genres or looking for a specific title, NetflixGPT enhances your streaming discovery experience.
👉 **[NetflixGPT Live Demo](https://netflixgpt-258c2.web.app)**

## Features
- Watch movie trailers playing in the background while browsing.
- Secure user authentication, including Sign Up, Sign In, and Sign Out functionality.
- Support for multiple languages on the search page.
- Browse movies by various categories such as Now Playing, Popular, Top Rated, and Upcoming.
- Fully responsive design for a seamless experience across both web and mobile devices.

## Technology Stack
- **Front-end:** React.js
- **Back-end:** Firebase integration in the backend for secure user authentication.

## Prerequisites
Before you begin, ensure you have the following installed on your system:
- [Node.js](https://nodejs.org/) (version 24.11.0 or later)
- npm (comes with Node.js)
- To verify if Node.js and npm are installed, run the following commands in your terminal:
  ```bash
  node -v
  npm -v

## Installation and Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/SurendraRavikumar/Netflix---GPT
2. Navigate to the project directory:
   ```bash
   cd netflix-gpt
3. Install dependencies:
   ```bash
   npm install
5. Start the application:
   ```bash
   npm run start
6. Open your browser and go to:
   ```bash
   http://localhost:3000
